01 / Traditional Software vs. AI Model

04 / DeepHunter · Algorithm 1 · Coverage-Guided Fuzzing

覆盖率引导模糊测试闭环（Guided vs. Random）

为什么 Algorithm 2 每次只做 1 次变异，DeepHunter 却能演化出多步连续变异？运行下方模拟器看清队列 Q 的回流机制：只有带来新覆盖率的变异样本 s' 才会被追加回 Q，在下一轮再次被抽中继续变异！

对应作业 2.2 简答 & Part 3（5 pts）
1. SelectNext(Q)从种子队列 Q 抽取一个种子 s（优先低频/多样性）
2. Algorithm 2对 s 执行 1 次有效蜕变变异，产出候选集 T
3. Run(DNN, T)批量喂给神经网络，记录预测结果与 NBC 增量
4. Oracle 分流预测出错 → 存入缺陷池 F（不放回队列）
5. CoverageGain未出错但覆盖率上升 → 追加回 Q，促成连续变异！

✅ 作业 2.2 简答题一针见血总结 当 Algorithm 2 的 Success 为 True 时，内层循环立刻 break，因此返回集合 T 中每张图片相对于输入种子 s 都只被施加了 1 次（one-time）变异。 而连续变异（Sequential Mutation）是在外层 Algorithm 1 中完成的：当某张变异图 s' 没有出错但带来了新的覆盖率增益（isCoverageGain）时，它会被 Q.append(s') 放回种子队列，后续再次被选中并送入 Algorithm 2 时就在已有变异基础上叠加新一轮变异。

06 / Quick Glossary

📚 核心术语表

一句话速查 DeepGauge、DeepHunter 与本次 Assignment 1 涉及的关键概念。

Quick Reference
术语一句话解释
Profiling（画像统计）用训练集跑一遍模型，记录每个神经元的最小/最大输出边界 [low_n, high_n]（对应 profile_DNN）
Major Function Region主功能区，即神经元激活值落在 [low_n, high_n] 内部的常规行为区间
Corner-Case Region角落区，即激活值突破 (-∞, low_n) 或 (high_n, +∞) 的训练未见极端区间
KMNC把每个神经元的主功能区均分成 k 段，衡量测试集踩中多少段的细粒度覆盖率
NBC（作业 2.1）神经元边界覆盖率：(|UpperCorner| + |LowerCorner|) / (2 × |N|)，专盯上下界角落区
SNAC强激活覆盖率：仅统计突破上界 > high_n 的比例 |UpperCorner| / |N|
TKNC / TKNP层级覆盖率：统计哪些神经元曾进入每层 Top-k 最活跃集合，及跨层 Top-k 组合模式数
Metamorphic Mutation蜕变变异：对图像施加变换后仍保持人眼语义不变（O(s') = O(s)），无需重新标注即可判 Bug
L₀ / L∞ 双阈值约束改动像素个数 L₀ < α·size 时幅度不限，否则单像素最大改动 L∞ < β·255（Equation 1）
CGF（覆盖率引导模糊测试）仅把带来覆盖率提升的变异体追加回种子队列 Q 继续变异，高效逼近角落区与缺陷
